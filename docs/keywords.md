# Keywords

A starter list of the search terms families use, grouped by need. It is a first draft to be corrected and extended by parents. Parent slang often finds more than the clinical term, so both belong here.

| Need | Search terms |
|---|---|
| Central line protection | Broviac line cover, Hickman line wrap, central line vest, CVC chest wrap, PICC line sleeve (infant), line securement clip |
| Bathing and swimming with a line | waterproof central line cover, dressing shield for bathing, dry suit for central line |
| TPN and pumps | TPN backpack toddler, infusion pump backpack, mini feeding pump backpack, IV pole clip for crib or stroller |
| G-tube | G-tube button pads, G-tube protective belt, tubie tape, extension set cover, feeding tube clip |
| Ostomy | infant ostomy pouch cover, pediatric ostomy belt, ostomy wrap baby |
| Clothing, NICU stage | micro preemie clothes, NICU-friendly side-snap shirt, IV-access onesie, velcro kimono preemie, CPAP hat |
| Clothing, as they grow | adaptive bodysuit tummy access, G-tube access onesie, line-access shirt toddler, adaptive pyjamas tube access |
| Oxygen and monitors | nasal cannula tender grips, cannula stickers, oxygen tubing clip, pulse ox wrap, oxygen tank backpack |
| Skin and high output (SBS) | micro preemie diapers, barrier cream, washable bed pads, waterproof crib pad |
| Safety and ID | medical alert car seat tag, seat belt cover central line, toddler medical ID bracelet |
| Organisation | medical supply organiser, dressing change kit caddy, emergency go-bag medical, medical binder |
